# vLLM-HUST KNorm

Owner-maintained extraction of the KNorm KV-cache compression work preserved
in the archived vLLM-HUST repository.

**Status: migration scaffold. This repository does not yet contain an
installable or runnable release.**

The target is a method extension behind one host-owned transactional
KV-compression lifecycle. Prefix caching and other components that mutate KV
block tables remain explicit conflicts until composition is proven.

See [PROVENANCE.md](PROVENANCE.md) and [MAINTAINERS.md](MAINTAINERS.md).
